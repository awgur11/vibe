# KINGAVTO — главная страница интернет-магазина

Готовая адаптивная вёрстка **HTML + CSS + JavaScript без сборщиков и внешних библиотек**, по утверждённому макету.

## Файлы

- `index.html` — разметка главной страницы;
- `styles.css` — оформление и адаптивные стили;
- `script.js` — меню, поиск, фильтрация товаров, избранное, демо-корзина, карусель новостей, проверка VIN;
- `assets/` — локальные изображения и логотип, подготовленные из согласованного визуального макета.

## Запуск

Откройте `index.html` в браузере. Если браузер запрещает некоторые операции в режиме `file://`, можно запустить локальный веб-сервер:

```bash
cd kingavto-site
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000`.

## Что работает

- Адаптивная шапка и раскрывающееся меню каталога;
- Статическая сетка из **12 категорий**;
- Поиск и фильтрация демо-товаров;
- Добавление в корзину, удаление и просмотр итоговой суммы;
- Избранное, хранящееся в `localStorage`;
- Стрелки, точки и горизонтальная прокрутка **карусели новостей**;
- Переключение VIN / параметры авто и клиентская валидация;
- Адаптивное отображение на смартфонах.

## Перенос в Laravel

1. Перенесите `assets/` и при необходимости `styles.css`, `script.js` в `public/` проекта.
2. Сохраните разметку как `resources/views/site/index.blade.php` (или разбейте на Blade-компоненты).
3. Используйте `{{ asset('styles.css') }}`, `{{ asset('script.js') }}`, `{{ asset('assets/...') }}` при подключении ресурсов.
4. Замените демонстрационные карточки товаров циклами `@foreach` и Eloquent-данными.
5. В `script.js` замените локальные операции с корзиной и поиск на AJAX-маршруты Laravel.
6. Подключите обработчик формы VIN с CSRF-защитой, валидацией и сохранением заявки в БД.
7. Замените вымышленные контактные сведения и демонстрационные цены, артикулы и публикации реальными.

**Важно:** это фронтенд-макет, а не готовая торговая платформа. Покупка, отправка VIN-запроса, реальные остатки, поиск по серверному каталогу и личный кабинет требуют backend-интеграции. Для публикации реального сайта дополнительно настройте SEO, условия доставки, политику конфиденциальности и обработку персональных данных.
